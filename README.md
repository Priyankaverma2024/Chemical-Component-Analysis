🧪 Analysis of Chemical Components in Cosmetics

📌 Project Overview

This project analyzes the chemical composition of cosmetic products to understand ingredient patterns across different product categories and skin types. The objective is to help users make informed decisions by identifying potentially harmful or beneficial ingredients and visualizing their distribution using data analysis and interactive visualization techniques.

The project uses Python for data manipulation and the Bokeh library for interactive plotting.
Using Python and ML

🎯 Objectives

Explore and clean cosmetic product ingredient data

Focus on specific product categories and skin types (e.g., dry skin cosmetics)

Identify common chemical components used in cosmetic formulations

Visualize ingredient distributions interactively

Provide insights to help consumers choose safer cosmetic products

📊 Dataset Description

The dataset contains information about cosmetic products, including:

Product category (e.g., moisturizers, cleansers, etc.)

Skin type suitability (e.g., dry, oily, sensitive)

Chemical ingredients used in the products

The analysis filters the data to focus on specific combinations such as products for dry skin and examines ingredient frequency and distribution.

📈 Key Features

Filtering cosmetic products by category and skin type

Cleaning and transforming ingredient data

Counting and ranking chemical components

Interactive visualizations using Bokeh

Easy-to-understand insights for non-technical users

📌 Results

Identification of the most common chemical ingredients used in cosmetic products.

Visual understanding of ingredient prevalence across product types.

Support for safer cosmetic selection through data-driven insights.
